# קו היתר · Rooftop Hypotenuse

A 3D grapple-parkour game over sunset Tel Aviv rooftops for Hebrew-speaking grade-8 students.
Your grapple rope has a fixed length L. The scan shows only how far across and how far up an
anchor is, never the straight distance, so Pythagoras decides every line: if a² + b² > L² the
rope falls short and you bounce off a striped awning and climb back.

Work in progress. See `progress.md`.

```bash
npm install
npm run dev    # http://localhost:5178
npm test
```
